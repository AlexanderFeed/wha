# Dataset sources

`data/words.jsonl` is generated by `tools/build_dataset.py`. It combines German noun headwords and gender from the German Wiktionary dump with Goethe vocabulary-list level labels.

## German Wiktionary / Kaikki

- Dump: [Kaikki German Wiktionary raw data](https://kaikki.org/dewiktionary/rawdata.html)
- Download used by the importer: [raw-wiktextract-data.jsonl.gz](https://kaikki.org/dewiktionary/raw-wiktextract-data.jsonl.gz)
- Wiktionary content is available under Creative Commons Attribution-ShareAlike and GNU Free Documentation License terms. Kaikki provides structured data extracted from Wiktionary; consult the linked project pages for current attribution and license details.
- Kaikki noun senses provide German glosses in `senses[].glosses`. English equivalents are taken from matching `translations[]` entries with `lang_code: "en"`, associated by sense index where available.
- Individual quiz entries link to their German Wiktionary page. Source translations are linked to their matching sense where available.

## Offline machine translations

- Senses without a Kaikki English translation can be filled locally with the German-to-English Argos Translate model. The model package is obtained through the [Argos Translate package index](https://github.com/argosopentech/argospm-index); the translation library is documented in the [Argos Translate project](https://github.com/argosopentech/argos-translate).
- Generated entries are marked with `translationSource: "machine"` in `data/words.jsonl` and in the quiz. These translations are automatic, may be inaccurate, and have not been human reviewed. The German Wiktionary page remains linked for checking each sense.

## Goethe-Institut vocabulary lists

- [A1 Start Deutsch 1 Wortliste (PDF)](https://www.goethe.de/pro/relaunch/prf/de/A1_SD1_Wortliste_02.pdf)
- [A2 Goethe-Zertifikat Wortliste (PDF)](https://www.goethe.de/pro/relaunch/prf/en/Goethe-Zertifikat_A2_Wortliste.pdf)
- [B1 Goethe-Zertifikat Wortliste (PDF)](https://www.goethe.de/pro/relaunch/prf/de/Goethe-Zertifikat_B1_Wortliste.pdf)

The Goethe PDFs supply the A1–B1 level labels. The B1 list identifies Goethe-Institut and ÖSD as copyright holders and requires prior written consent for reuse beyond statutory exceptions; permission for this project's use has been confirmed by the project owner. The importer does not copy Goethe definitions or example sentences into the app dataset.

## Leipzig Corpora Collection

- [Mixed Typical 2011, 1M corpus archive](https://downloads.wortschatz-leipzig.de/corpora/deu_mixed-typical_2011_1M.tar.gz)
- [Download file format documentation](https://wortschatz.uni-leipzig.de/public/documents/Format_Download_File-deu.pdf)

The word-frequency list is used only to place nouns that do not match the Goethe A1–B1 lists. Nouns ranked within the first 50,000 are placed in a provisional B2 tier; rarer or unranked nouns are placed in provisional C1. These are app-specific estimates; corpus frequency alone does not establish a CEFR level. The Leipzig word list supplies frequencies, not B2/C1 classifications.

## Rebuilding

Run `python -m pip install -r requirements.txt`, then `python tools/build_dataset.py`. The source files are downloaded into `data/sources/`, which is ignored by Git. Review and retain the applicable source notices and permissions when redistributing generated data.

## Rektion trainer

- Reference material consulted while preparing the fixed-preposition and case patterns includes German Wiktionary and its [guide to prepositional complements](https://de.wiktionary.org/wiki/Hilfe:pr%C3%A4positionale_Erg%C3%A4nzung). References include [warten](https://de.wiktionary.org/wiki/warten), [freuen](https://de.wiktionary.org/wiki/freuen), [bestehen](https://de.wiktionary.org/wiki/bestehen), and the genitive constructions [bedurfen](https://de.wiktionary.org/wiki/bed%C3%BCrfen) and [enthalten](https://de.wiktionary.org/wiki/enthalten).
- The trainer's example sentences and English glosses are original app content, not copied from a textbook. CEFR placements are suggestions marked by `levelUnverified`; `needsReview` contains only grammar questions.
- These links document representative checks, not a source citation for every individual entry.
